# Twitter/X

X (formerly Twitter) operates the X Developer Platform — programmatic access to the public conversation through the X API v2: Posts, Users, Direct Messages, Lists, Spaces, Communities, Trends, News, Media, and a real-time surface of streaming endpoints and webhook products (X Activity, Account Activity, Filtered Stream Webhooks). The platform runs credit-based Pay-Per-Use pricing with a Developer Console at console.x.com, first-party Python and TypeScript XDKs, the xurl CLI, a local Playground mock server, and a deep agent-native surface: llms.txt, AGENTS.md, skill.md, and hosted MCP servers for both the API (api.x.com/mcp) and its documentation (docs.x.com/mcp).
